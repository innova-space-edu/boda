# Invitación digital Carolina & Esthefano

Base limpia para invitación digital vertical con scroll.

## Estructura

- `index.html`: página principal.
- `styles.css`: estilos generales y estructura responsive.
- `assets/invitacion-base.svg`: imagen/base vertical de la invitación.

## Cloudflare Pages

Configuración recomendada si Cloudflare pide build:

- Build command: `npm run build`
- Output directory: `dist`

Si Cloudflare está configurado como sitio estático sin build, también puede servir directamente desde la raíz.
