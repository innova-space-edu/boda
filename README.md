# Invitación digital Carolina & Esthefano

Base limpia para invitación digital vertical con scroll.

## Estructura

- `index.html`: página principal.
- `styles.css`: estilos generales y estructura responsive.
- `assets/invitacion-base.svg`: imagen/base vertical de la invitación.

## Cloudflare Pages

Configuración recomendada:

- Build command: `npm run build`
- Output directory: `out`

El build copia la página estática completa dentro de `out`, que es la carpeta que Cloudflare está esperando en este despliegue.
