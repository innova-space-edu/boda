# Fondos de la invitación

Reemplaza estas imágenes por diseños propios, manteniendo los nombres.

Formato recomendado para WhatsApp/celular: 1080 x 1920 px.
Formatos aceptados: jpg, jpeg, png.

Cada fondo debe tener el centro relativamente limpio porque el texto y botones se colocan encima con código.
